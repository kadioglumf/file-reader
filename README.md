# 📄 File Reader

A lightweight Java library for reading and converting Excel (`.xlsx`) and CSV files into Java objects. This project is designed to simplify data ingestion from structured files by leveraging annotations and reflection.

---

## 🚀 Features

- ✅ Read Excel (`.xlsx`) files and map them to Java models  
- ✅ Read CSV files and convert them into Java object lists  
- ✅ Supports dynamic field mapping using annotations  
- ✅ Simple and clean API with extensible architecture
